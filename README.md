## 真实的短板：退款、续费、到货

先说退款，这是最容易被忽略的部分。按照荔枝商店的售后政策（页面标注 2026 年 5 月更新），软件这类数字化商品不适用七天无理由退货，一经交付原则上不退不换。7 个自然日内能申请退款的只有几种特定情形：

- 注册激活出问题，且客服已和开发商确认能回收或销毁已交付的激活码、授权文件；
- 实际交付时间比订单“处理中”状态对应的预期晚 2 个工作日以上，订单还没变成“已完成”；
- 订单状态显示“处理异常”并持续 2 个工作日以上；
- 买错版本（比如 Mac 用户买了 Windows 版），并且已经重新买了正确版本。

符合条件的话，商店在 7 个工作日内处理，退款再等 1 到 2 个工作日回到原支付账户。也就是说，别指望“先买了试试，不好用再退”这条路，订阅类商品尤其不适用。

政策里还有一条要留个心眼：商品规格描述是基于开发商提供的说明，如果开发商后来单方面调整授权政策导致跟描述不符，商店不承担赔偿或退款责任。这话说得挺直白，你买的是“代理帮你下单”的服务，长期授权政策的屁股在微软那边。
